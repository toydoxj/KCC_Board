### CH-STUD 후면 끼움 보드 좌표 규칙

- CH-STUD는 후면 석고보드가 CH 홈에 끼워져 고정되는 구조이므로 후면 보드는 1장만 허용한다.
- 일반 CH-STUD의 후면 보드는 25T로 고정한다.
- CH-STUD(개량형)의 후면 보드는 현 자재 DB 기준 12.5T(명목 12T 계열)로 고정한다.
- 중립축 산정 시 후면 보드의 단면적·자체I·도심은 포함하되, 후면 보드 두께는 스터드 및 전면 보드의 적층 좌표에 더하지 않는다.
- 따라서 CH-STUD 스터드 도심은 `y_bottom + 후면보드두께 + cy`가 아니라 `cy`이고, 전면 보드 첫 레이어의 하단 좌표는 `후면보드두께 + H`가 아니라 `H`이다.
- 후면 끼움 보드와 CH-STUD의 합성은 피스 전단연결이 아니라 넓은면 끼움 고정으로 보고 합성률 100%를 적용한다. 엔진에서는 해당 후면 보드의 전단누계를 보드 축강도와 동일하게 둔다.

### I-STUD 후면 고정 보드 좌표 규칙

- I-STUD는 CH-STUD와 동일하게 후면 방화 25T 보드 1장을 붙이고 내부쪽으로 연결하는 형식으로 본다.
- 중립축 산정 시 후면 방화 25T의 단면적·자체I·도심은 포함하되, 후면 보드 두께는 스터드 및 전면 보드의 적층 좌표에 더하지 않는다.
- 따라서 I-STUD 스터드 도심은 `y_bottom + 25 + cy`가 아니라 `cy`이고, 전면 보드 첫 레이어의 하단 좌표는 `25 + H`가 아니라 `H`이다.
- 후면 방화 25T 보드와 I-STUD의 합성률은 100%로 적용한다. 엔진에서는 해당 후면 보드의 전단누계를 보드 축강도와 동일하게 둔다.

### R-STUD 1P 보드-스터드 순 간격 규칙

- R-STUD는 1P 석고보드와 스터드 사이에 12mm의 순 간격이 형성된다.
- 후면 1P 보드가 있으면 후면 보드 적층 끝과 스터드 하단 사이에 12mm를 더한다.
- 전면 1P 보드가 있으면 스터드 상단과 전면 보드 시작 좌표 사이에 12mm를 더한다.
- 이 간격은 단면적이나 질량은 없지만, 각 레이어의 도심거리와 중립축 산정에는 반영한다.

### C-STUD 중앙부 이음 조립 단면

- 스터드 간격: 25mm
- 전체 높이: `H_total = h + 25 + h`
- 단면적: `A_total = 2 × A`
- 스터드 자체 단면2차모멘트 산정 보정계수: 미적용
- 스터드 자체 단면2차모멘트: `Ix = 2 × [A × (h + 25/2 − cy)^2 + Ix0]` (대칭 C형: 거리 = h/2 + 12.5)
  - 2026-10 수정: 종전 `(h + 25/2)`는 조립 도심~스터드 도심 거리를 h/2만큼 과대 산정(50S-45-08: 1,149,480 → 509,527 mm⁴, DXF 단면 기준)
- 단면계수: 부분합성 `S = I_NA,stud / c_max`, 스터드 단독 `S = Ix / (h + 12.5)`, 이후 Se/Sx 적용

### I_eff 보정계수

아래 보정계수는 합성률 `η` 또는 완전합성 `I_full` 산정에는 적용하지 않고, 최종 `I_eff`에만 곱함.

2026-10 재보정: DXF 단면성능 교체·중앙부이음 관성 수정으로 `I_eff(raw)`가 변한 유형은 시험체 조건(L=2400, `tests/golden/requested_shape_cases.json`)의 보정 강성 `R·I_eff(raw)`를 유지하도록 `R_new = R_old × I_eff,raw,old / I_eff,raw,new`(소수 2자리)로 재산정함. 변동 0.7% 미만(C 기본·맞댐, HR, RV, R)은 기존값 유지.

### 피스 활용도 기준 단방향 강성 보정 — 2026-10-20 (E-8)

`I_eff = max(R · I_eff,raw · min[1, (u/u_ref)^(1−m)], I_s,자체)`

| 항목 | 식 / 값 | 비고 |
|------|---------|------|
| u/u_ref | `(q·s·L/2) / V_ref × max(p_i / p_ref,i)` | 처짐 하중(활하중) 지점 전단력 / 시험 기준 전단력 × 피치비 |
| V_ref | `306 kgf × 9.81 × 1,500 / 2,400 = 1,876 N` | 시험 최대 가력 시 짧은 전단경간 전단력(R 정의 하중 수준) |
| p_ref | 1P(내측, 스터드 인접) 600 / 2P 300 / 3P(외측) 300 mm | 시험 피스 간격(엑셀 VAR. C32:C34). 엔진 `bolt.pitch`는 [외측, 중간, 내측] 순서 |
| m | C 맞댐·중앙부 1.49, C 기본 1.38, CH 1.25, HR 1.33, MP 1.24, RV 1.25, T.silent 1.29, R 1.11, I 1.26 (미등록 1.49) | 실측 δ = c·Mᵐ 회귀(분석 시트 0724, ch4) |
| 성질 | u ≤ u_ref → 1.0(현행 R 유지), u > u_ref → 강성 저감 | 시험 범위 초과 하중 수준만 보수 처리 |

| C37(Wp) | `=N13` (=SUM(G13:M13)) | **총중량 — FIX-01 반영(후면 포함)** |
| C40(Sds) | `=C39*2.5*2/3*C38` | =S·2.5·(2/3)·Fa (Fa는 KDS 41 17 00 지반등급 S1~S5 표로 자동 산정, S5 기반암 깊이 불분명 시 110% 적용) |
| C41(Fp) | `=0.48*C40*C42*C37` | 비구조요소 수평지진력 (OI-02) |
| C43(M_E) | `=1/4*C41*C20*10^-3` | **지진모멘트 — 집중하중 가정(1/4, 의도됨)** |

## 9. 반력 산정

스터드 간격당 산정된 반력을 `spacing_m`으로 나누어 m당 필요 반력 `kN/m`으로 환산함.

| 항목 | 수식 | 의미 |
|------|------|------|
| Rh,L | `(L * H * B) / 2 / B` (= `L * H / 2`) | 활하중 반력. L=활하중 kN/m², H=검토높이 m, B=스터드간격 m |
| Rh,E | `(Fp / 2 * 2) / B` | 지진하중 반력. Fp는 스터드 간격당 지진력 kN |
| Rh,0.7E | `0.7 * Rh,E` | 지진 조합 반력 |
| Rh,0.75L+0.75(0.7E) | `0.75 * Rh,L + 0.75 * 0.7 * Rh,E` | 복합 조합 반력 (KDS 41 10 15 허용응력 조합, 2026-10 수정: 종전 0.75L+0.7E) |
| Rh,req | `MAX(Rh,L, Rh,0.7E, Rh,0.75L+0.75(0.7E))` | m당 필요 반력 |
| 앵커 성능 | 기본 `0.4 kN/개`, 입력 변경 가능 | 앵커 1개당 저항 성능 |
| 검토 앵커 간격 | 입력값, 기본 `450 mm` | 150~600mm 범위, 50mm 단위 |
| 허용 앵커 간격 | `앵커성능 / Rh,req * 1000` 후 50mm 단위 내림 | 필요 반력 기준 허용 앵커 간격 mm |
| 앵커 사용률 | `Rh,req / (앵커성능 / 검토앵커간격_m)` | 1.0 이하 O.K 기준 |
| 앵커 기준 최대높이 | 50mm 단위 탐색 | 응력·처짐·앵커 사용률을 모두 만족하는 최대 높이 |
