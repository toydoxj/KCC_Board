## 1-13. 보정계수 R 산정 기준 변경·E-8 기준 피스력 변경 (2026-10-24, E-11·E-8, 사용자 승인)

- 종전 "시험체 강성 유지 재보정(R_new = R_old × Ieff,raw,old / Ieff,raw,new)" 폐기
- 정의: R = 허용처짐(H/240) 상태의 사용하중 모멘트 M_L = q·s·H²/8에서의 실측 할선강성 I_test / 엔진 Ieff,raw(L = 2,400). 설계 높이 H의 δ–M 그래프에서 H/240 수직선과 실측 환산 곡선의 교점을 계산 직선(R·Ieff,raw(H))이 지나도록 하는 R
- 시험 환산: 단순보 1점 가력(a 1,500, b 900, L 2,400 mm). P = M_L/(a·b/L), I_test = K·P/δ_t, K = a²b²/(3EL). δ_t는 분석 시트 0724의 Q열 M(N·m)·U열 ch4 변위(최대모멘트까지)에서 선형 보간
