## 1-1. 피스 인장 검토 신설 (D-7, B안)

- `_screw_tension_result`: T = q·s·p_max, 풀아웃 Pnot = 0.85·tc·d·Fu2 (AISI S100-16 Eq. J4.4.1-1, Ω 3.0), 풀스루 = 입력 공칭값(기본 343 N)/Ω
- 요청 필드 `screw_pull_through_nominal_N`, 결과 `screw_tension_verdict`, 중간값 `screw_*`
- N.G이면 최대 산정높이·앵커 기준높이 0 (모든 검토 만족 조건에 포함)
- 11개 시편: 풀아웃 사용률 0.11~0.39, 풀스루 0.30~0.81 → 전부 O.K, 허용높이 불변

## 1-2. 피스 전단 강성·강도 분리 (2026-10-19, B안 확정)

- Mn 보드항 피스 강도 상한: AISI S240-20 해설 Table C-B3.2-1 극한/2.0 (12.7 mm 258 N, 15.9 mm 이상 302.5 N). η·Ieff·R 불변
- CH·I-STUD 후면 보드: 완전합성 → 피스 체결(300 mm, 2개)
- 영향(11개 시편, 내진 부분합성): Mn 30~85% 감소, 허용높이는 **I-STUD 75-06만 6,400 → 5,600 mm(응력 지배)**, 나머지 불변. 비내진 불변

## 1-3. 피스 활용도 기준 단방향 강성 보정 (2026-10-20, E-8)

- `I_eff = max(R·I_eff,raw·min[1, (u/u_ref)^(1−m)], I_s)`, u/u_ref = (q·s·L/2)/1,876 N × 피치비, m = 형식별 실측 회귀 지수
- 11개 시편·골든 케이스: u/u_ref = 0.15~0.32 → 보정계수 1.0, 결과 불변
- 고하중·넓은 피치(u/u_ref > 1)에서만 강성 저감. 중간값 `screw_utilization_ratio`, `stiffness_curve_exponent_m`, `stiffness_load_factor` 출력

## 1-4. 석고보드 항복비 종류·두께별 적용 (2026-10-21, B-3)

- Fy = Fu × 항복비. 항복비 = KCC 휨-변위 시험(41개 시험체) Py/Pu(초기 선형 회귀 직선 대비 하중 5% 저하점) 평균
- 시험: 일반 9.5/12.5/15 = 0.52/0.55/0.59, 방화 12.5/15/19/25 = 0.56/0.70/0.65/0.80, 고강도일반 12.5 = 0.61, 전방수 12.5/15 = 0.48/0.38(하한 미적용, 사용자 결정)
- 준용(미시험, 심재 계열·단위중량 기준): 방수·방균 → 일반 동일 두께, 방화방수 → 방화 동일 두께, 차음 9.5·12.5 → 방화 12.5, 고강도일반 15·고강도전방수 12.5 → 고강도일반 12.5
- 표에 없는 보드는 기본값 0.6(근거 '기본값'). 위치: `constants.BOARD_YIELD_RATIO_BY_BOARD`, repository가 Fy 산정·SQLite 마이그레이션(schema 6)
- API `GET` 보드 목록에 `yield_ratio`, `yield_ratio_source` 추가, 계산서 보드 물성 표에 'Fy/Fu (근거)' 열 추가
- R 재보정(시험 보드 방화 19 0.65 등으로 시험조건 η 0.1226 → 0.1132, 시험 강성 유지): C 0.70 → 0.72, 중앙부 0.35 → 0.36, CH 0.65 → 0.67, T.silent 0.45 → 0.46, R 0.26 → 0.27, I 0.87 → 0.90, HR 0.71 → 0.73, RV 0.43 → 0.44, MP 0.42 → 0.43 (C 기본 일면 1.0 유지, 계산 1.006)
- 11개 시편 허용높이 변화: 02 5,050 → 5,000(전 조건), 03 6,650 → 6,600(부분합성·비내진 STUD만), 07·08 6,350 → 6,300(부분합성), 그 외 불변(R 소수 2자리 반올림 영향)
